# Página Liturgia

A aba "Liturgia" do menu: leituras do dia em destaque e, ao lado, o santo do dia e a missa de hoje.

- **Desktop (≥ 1000px):** duas colunas. Leituras à esquerda, que é o conteúdo principal; santo do dia e horário de hoje à direita.
- **Celular:** uma coluna, nesta ordem: leituras, santo, horário. Quem chega pelo link do WhatsApp quer o Evangelho primeiro.
- Uma navegação de datas (‹ ontem · amanhã ›) é um bom acréscimo, para quem prepara a reflexão do Evangelho com antecedência.
- Na página inicial, use o resumo de uma linha (`ros-liturgia-resumo`) com link para cá.
