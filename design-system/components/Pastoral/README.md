# Pastoral

Card de pastoral ou movimento: o que é, quando se encontra, como entrar.

- O filete colorido de 4px no topo diz a família: `acao` (padrão, paroquial), `--mariano` (movimentos marianos e juventude), `--franciscano` (terracota), `--social` (verde: cestas, reciclagem).
- Sempre: nome, uma frase do que faz, quando se reúne, como entrar em contato e um botão.
- Em grade com `ros-grade`: 1 coluna no celular, 2 no tablet, 3 no desktop, sem quebras manuais.
