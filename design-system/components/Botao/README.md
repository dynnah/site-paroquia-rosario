# Botão

Botões com verbo, altura mínima de 44px, em quatro variações.

- **Primário** (`ros-btn--primario`, `acao`: marrom médio): a ação principal da tela. Uma por tela.
- **Secundário** (`ros-btn--secundario`, mariano contornado): ações de apoio.
- **Fantasma** (`ros-btn--fantasma`): links de "saiba mais" dentro de cards.
- **Claro** (`ros-btn--claro`, creme): só sobre fundos `marrom`.
- `ros-btn--bloco` ocupa a largura toda. Use no celular quando o botão é a última coisa de um card.
- Ícone opcional à esquerda, 18px, traço 1.75px.
